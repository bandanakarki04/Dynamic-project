# Team Working Method

## Team Communication

The team communicated primarily through Microsoft Teams and WhatsApp. Regular discussions were held to review progress, solve problems, and coordinate upcoming tasks.

## Task Management

Jira was used for task tracking and project management. Tasks were assigned to team members according to their responsibilities and monitored throughout the project.

## Version Control

GitHub was used for source code management and collaboration. Team members developed features in separate branches and merged completed work into the main branch after testing and review.

## Development Process

The project was developed using Laravel. Development was carried out incrementally, with team members implementing assigned features, testing functionality, and integrating changes into the shared repository.

## Testing and Quality Assurance

Features were tested locally before being merged into the main branch. Integration testing was performed after combining work from multiple team members. Merge conflicts and issues were resolved collaboratively.

## Documentation

Project documentation was maintained throughout development. AI usage was documented in AI_USAGE.md, and weekly progress snapshots were recorded to track project development and milestone completion.

## Collaboration Practices

- Weekly progress reviews were conducted.
- Team members reported task completion through Jira.
- GitHub was used for code sharing and version tracking.
- Team members assisted each other in resolving technical issues and merge conflicts.
