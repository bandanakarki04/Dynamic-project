# AI Usage Documentation

## AI Tool Used
- Microsoft Copilot

## Purpose of AI Usage

AI was used as a supporting tool during the development process. The team used AI to assist with understanding Laravel concepts, debugging issues, Git and GitHub workflows, and documenting project progress.

## Areas Where AI Was Used

### Development Support
- Understanding Laravel models, controllers, routes, and migrations.
- Reviewing CRUD implementation approaches.
- Understanding database relationships and validation concepts.

### Git and GitHub Assistance
- Resolving merge conflicts.
- Understanding branch management and merge procedures.
- Assistance with Git commands and repository synchronization.

### Documentation Support
- Drafting project documentation.
- Assisting with weekly snapshot reports.
- Assisting with the Team Working Method document.

## Verification

All AI-generated suggestions were reviewed, modified where necessary, and tested by team members before being included in the project.
